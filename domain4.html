Domain 4: Network Security

14% of the CompTIA Network+ N10-009 Exam

Domain 4 Overview

Network Security is a critical domain representing 14% of the CompTIA Network+ exam. This domain covers fundamental security concepts, attack types, and defensive measures essential for protecting modern networks.

Key Learning Objectives:

  • 4.1 - Explain the importance of basic network security concepts
  • 4.2 - Summarize various types of attacks and their impact to the network
  • 4.3 - Given a scenario, apply network security features, defense techniques, and solutions

Study Strategy for Domain 4:

Focus on understanding both theoretical concepts and practical implementation. Know the CIA triad, various attack vectors, and how to implement appropriate security controls. Pay special attention to scenario-based questions involving network segmentation and access control.

4.1 Basic Network Security Concepts

Understanding fundamental security principles is crucial for implementing effective network protection strategies.

CIA Triad

Confidentiality, Integrity, and Availability (CIA)

Confidentiality: Ensuring information is accessible only to authorized users

Integrity: Maintaining accuracy and completeness of data

Availability: Ensuring information and resources are accessible when needed

Common Security Terminology

Risk

The potential for loss or damage when a threat exploits a vulnerability

Vulnerability

A weakness in a system that can be exploited by a threat

Threat

Any potential danger that could exploit a vulnerability

Exploit

A method used to take advantage of a vulnerability

Logical Security

Encryption

Data in Transit

Protecting data while it moves across networks using protocols like TLS/SSL, IPSec, and VPNs

Data at Rest

Protecting stored data using disk encryption, database encryption, and file-level encryption

Certificates and PKI

Public Key Infrastructure (PKI)

Framework for managing digital certificates and public key encryption. Includes Certificate Authorities (CAs), Registration Authorities (RAs), and certificate repositories.

Self-signed Certificates

Certificates signed by the same entity that created them, not by a trusted CA. Often used in testing environments or internal networks.

Identity and Access Management (IAM)

Authentication Methods

  • Multifactor Authentication (MFA): Using multiple authentication factors
  • Single Sign-On (SSO): One login for multiple systems
  • RADIUS: Remote Authentication Dial-in User Service
  • LDAP: Lightweight Directory Access Protocol
  • SAML: Security Assertion Markup Language
  • TACACS+: Terminal Access Controller Access Control System Plus
  • Time-based Authentication: Time-sensitive tokens (TOTP)

Authorization Concepts

  • Least Privilege: Users get minimum access needed
  • Role-based Access Control: Access based on user roles

Geofencing

Location-based Security

Creating virtual boundaries to control access based on geographic location. Used to restrict access to sensitive resources when users are outside approved areas.

Physical Security

Cameras

Video surveillance systems for monitoring and recording physical access to network infrastructure. Types include IP cameras, analog cameras, and PTZ (Pan-Tilt-Zoom) cameras.

Locks

Physical access controls including:

  • Traditional key locks
  • Electronic locks with keypads
  • Smart cards and proximity readers
  • Biometric locks
  • Cable locks for equipment

Deception Technologies

Honeypot

A decoy system designed to attract and detect attackers. Appears to be a legitimate target but is monitored and isolated from production systems.

Honeynet

A network of honeypots that simulates a complete network environment to study attack patterns and techniques.

Audits and Regulatory Compliance

Data Locality

Requirements for where data can be stored and processed based on legal and regulatory requirements. Important for cloud deployments and international operations.

Payment Card Industry Data Security Standards (PCI DSS)

Security standards for organizations that handle credit card data. Includes requirements for:

  • Secure network architecture
  • Cardholder data protection
  • Vulnerability management
  • Access control measures
  • Network monitoring
  • Information security policies

General Data Protection Regulation (GDPR)

European Union regulation governing data protection and privacy. Key requirements include:

  • Data subject consent
  • Right to erasure (right to be forgotten)
  • Data portability
  • Privacy by design
  • Breach notification requirements

Network Segmentation Enforcement

Internet of Things (IoT) and Industrial IoT (IIoT)

Segmenting IoT devices due to their often weak security posture and need for isolation from critical network resources.

SCADA, ICS, and OT

SCADA: Supervisory Control and Data Acquisition systems

ICS: Industrial Control Systems

OT: Operational Technology

These systems require special security considerations and network segmentation due to their critical nature and legacy protocols.

Guest Networks

Isolated network segments for temporary users, preventing access to internal resources while providing internet connectivity.

Bring Your Own Device (BYOD)

Security policies and network segmentation for personal devices used for business purposes. Often involves device registration, policy enforcement, and limited network access.

4.2 Types of Network Attacks

Understanding various attack vectors helps in implementing appropriate defensive measures.

Network-Based Attacks

Denial-of-Service (DoS) / Distributed Denial-of-Service (DDoS)

DoS: Attack from a single source overwhelming a target system

DDoS: Coordinated attack from multiple sources (botnet)

Impact: Service unavailability, resource exhaustion, business disruption

Common Types: TCP SYN flood, UDP flood, ping flood, amplification attacks

VLAN Hopping

Attack where an attacker gains access to traffic on other VLANs that should be segmented

Methods: Switch spoofing, double tagging

Impact: Unauthorized access to segmented network resources

Media Access Control (MAC) Flooding

Overwhelming a switch's MAC address table with fake MAC addresses

Impact: Switch operates in fail-open mode, broadcasting all traffic

Result: Network becomes like a hub, allowing traffic sniffing

Address Resolution Protocol (ARP) Poisoning/Spoofing

ARP Poisoning: Corrupting ARP cache with false MAC-IP mappings

ARP Spoofing: Sending fake ARP responses to redirect traffic

Impact: Man-in-the-middle attacks, traffic interception

DNS Poisoning/Spoofing

DNS Poisoning: Corrupting DNS cache with false DNS records

DNS Spoofing: Providing false DNS responses to queries

Impact: Redirecting users to malicious websites, data theft

Rogue Devices and Services

Rogue DHCP: Unauthorized DHCP server providing malicious network configuration

Rogue AP: Unauthorized wireless access point potentially intercepting traffic

Impact: Network compromise, data interception, malicious redirection

Evil Twin

Malicious wireless access point that mimics a legitimate Wi-Fi network

Purpose: Trick users into connecting to capture credentials and data

Impact: Credential harvesting, traffic interception, malware distribution

On-path Attack (Man-in-the-Middle)

Attacker intercepts communication between two parties

Methods: ARP spoofing, DNS hijacking, Wi-Fi eavesdropping

Impact: Data theft, credential harvesting, transaction manipulation

Malware

Malicious software designed to damage or gain unauthorized access

Types: Viruses, worms, Trojans, ransomware, rootkits, botnets

Impact: Data theft, system compromise, service disruption, financial loss

Social Engineering Attacks

Phishing

Fraudulent emails or messages designed to trick users into revealing sensitive information

Types: Email phishing, spear phishing, whaling, smishing (SMS), vishing (voice)

Impact: Credential theft, malware installation, financial fraud

Dumpster Diving

Searching through trash and discarded materials for sensitive information

Targets: Printed documents, backup media, hardware components

Impact: Information disclosure, identity theft, system access

Shoulder Surfing

Observing someone entering passwords, PINs, or other sensitive information

Methods: Direct observation, cameras, binoculars

Impact: Credential theft, unauthorized access

Tailgating

Following authorized personnel through secure entry points without proper authentication

Also known as: Piggybacking

Impact: Unauthorized physical access, facility compromise

4.3 Network Security Features and Solutions

Implementing appropriate security controls to protect against identified threats and vulnerabilities.

Device Hardening

Disable Unused Ports and Services

Remove or disable unnecessary network services, protocols, and physical ports

Benefits: Reduces attack surface, improves performance, simplifies management

Examples: Disabling Telnet, unused routing protocols, unnecessary physical switch ports

Change Default Passwords

Replace manufacturer default passwords with strong, unique credentials

Best Practices:

  • Use complex passwords with minimum 12 characters
  • Include uppercase, lowercase, numbers, and symbols
  • Avoid dictionary words and personal information
  • Use unique passwords for each device
  • Implement regular password rotation policies

Network Access Control (NAC)

Port Security

Controls access to switch ports based on MAC addresses

Features:

  • MAC address limiting (maximum devices per port)
  • Static MAC address assignment
  • Dynamic MAC learning
  • Sticky MAC addresses (learned addresses saved to config)
  • Violation actions: shutdown, restrict, protect

802.1X Port-Based Authentication

IEEE standard for port-based network access control

Components:

  • Supplicant: Client device requesting access
  • Authenticator: Network device (switch/AP) controlling access
  • Authentication Server: RADIUS server validating credentials

Process: EAP (Extensible Authentication Protocol) over LAN

MAC Filtering

Allow or deny network access based on device MAC addresses

Limitations: MAC addresses can be spoofed, difficult to manage at scale

Use Cases: Small networks, additional security layer, device whitelisting

Key Management

Encryption Key Management

Secure generation, distribution, storage, and disposal of cryptographic keys

Key Lifecycle:

  • Generation using strong random number generators
  • Secure distribution through established channels
  • Storage in hardware security modules (HSMs) or secure key stores
  • Regular rotation based on security policies
  • Secure disposal when keys are no longer needed

Security Rules

Access Control Lists (ACLs)

Rules that define which users or systems can access specific resources

Types:

  • Standard ACLs: Filter based on source IP address
  • Extended ACLs: Filter based on source/destination IP, ports, protocols
  • Named ACLs: Use descriptive names instead of numbers

Best Practices: Implicit deny, most specific rules first, regular review

URL Filtering

Controlling access to websites based on URLs, categories, or content

Methods:

  • Blacklist (deny specific URLs/categories)
  • Whitelist (allow only specific URLs/categories)
  • Category-based filtering (social media, gaming, adult content)
  • Real-time content analysis

Content Filtering

Examining and controlling data based on content characteristics

Applications:

  • Email filtering (spam, malware, data loss prevention)
  • Web content filtering (inappropriate content, malware)
  • File type restrictions
  • Data loss prevention (DLP) based on content patterns

Security Zones

Trusted vs. Untrusted Networks

Trusted Zone: Internal network with higher security assurance

  • Corporate LAN
  • Management networks
  • Internal servers and databases

Untrusted Zone: External networks with unknown security posture

  • Internet
  • Partner networks
  • Guest networks

Screened Subnet (DMZ)

Semi-trusted network zone between internal and external networks

Purpose: Host public services while protecting internal network

Common Services:

  • Web servers
  • Email servers
  • DNS servers
  • FTP servers
  • VPN concentrators

Security: Dual firewall architecture or single firewall with multiple interfaces

Exam Tips for Domain 4

Key Study Focus Areas:

  • CIA Triad: Know all three components and their practical applications
  • Attack Types: Understand the methods, impacts, and mitigation strategies
  • 802.1X: Know the three components and the authentication process
  • Network Segmentation: Understand DMZ, VLANs, and zone-based security
  • Compliance: Basic understanding of PCI DSS and GDPR requirements

Common Exam Question Types:

  • Scenario-based questions about implementing security controls
  • Attack identification and appropriate countermeasures
  • Security zone design and implementation
  • Authentication and authorization methods
  • Physical security considerations

Performance-Based Question Preparation:

  • Practice configuring ACLs on routers and switches
  • Understand VLAN configuration and security implications
  • Know how to implement port security features
  • Be familiar with firewall rule configuration
  • Understand wireless security configuration (WPA2/WPA3, enterprise authentication)

Memory Aids:

  • CIA: Confidentiality, Integrity, Availability
  • 802.1X: Supplicant, Authenticator, Authentication Server
  • AAA: Authentication, Authorization, Accounting
  • Social Engineering: People are often the weakest link
  • Defense in Depth: Multiple layers of security controls

Final Preparation Tips:

  • Review real-world security incidents and their causes
  • Practice identifying attack types from network traffic patterns
  • Understand the business impact of different security breaches
  • Know when to escalate security incidents
  • Practice with hands-on labs for configuration tasks
