CompTIA Network+ N10-009

8-Week Interactive Course Outline

Exam Information

The CompTIA Network+ certification exam validates the knowledge and skills required to establish network connectivity, explain documentation purposes, configure network services, and troubleshoot network issues.

Exam Details

  • Exam Code: N10-009
  • Questions: Maximum of 90
  • Duration: 90 minutes
  • Question Types: Multiple-choice and performance-based
  • Experience: 9-12 months recommended

Domain Breakdown

  • 1.0 Networking Concepts: 23%
  • 2.0 Network Implementation: 20%
  • 3.0 Network Operations: 19%
  • 4.0 Network Security: 14%
  • 5.0 Network Troubleshooting: 24%

Week 7 - Network Troubleshooting Part 1 ▶

Domain 5.0 - Methodology and Hardware Issues (24% of exam)

Learning Focus

Systematic troubleshooting methodology, physical layer issues, cabling problems, and interface troubleshooting techniques.

3
Objectives
24%
Exam Weight
  • 5.1 Explain the troubleshooting methodology ▶
    • 1. Identify the problem: Gather information, Question users, Identify symptoms, Determine changes, Duplicate problem, Approach individually
    • 2. Establish theory: Question the obvious, Consider multiple approaches (Top-to-bottom/bottom-to-top OSI, Divide and conquer)
    • 3. Test theory: If confirmed determine next steps, If not confirmed establish new theory or escalate
    • 4. Establish plan of action
    • 5. Implement solution or escalate
    • 6. Verify functionality and preventive measures
    • 7. Document findings, actions, outcomes, lessons learned
  • 5.2 Given a scenario, troubleshoot common cabling and physical interface issues ▶
    • Cable issues: Incorrect cable (Single/multimode, Cat5/6/7/8, STP vs. UTP), Signal degradation (Crosstalk, Interference, Attenuation), Improper termination, TX/RX transposed
    • Interface issues: Increasing counters (CRC, Runts, Giants, Drops), Port status (Error disabled, Admin down, Suspended)
    • Hardware issues: PoE (Power budget exceeded, Incorrect standard), Transceivers (Mismatch, Signal strength)
  • 5.3 Given a scenario, troubleshoot common issues with network services ▶
    • Switching issues: STP (Network loops, Root bridge selection, Port roles/states), Incorrect VLAN assignment, ACLs
    • Route selection: Routing table, Default routes
    • Addressing issues: Address pool exhaustion, Incorrect default gateway, Incorrect IP address, Duplicate IP address, Incorrect subnet mask
