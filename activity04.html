What you need to know

The core knowledge an entry-level network specialist uses when managing static and RIPv2 routing.

How a router picks a path

A router forwards a packet by looking up the destination IP in its routing table. Three rules decide which route wins:

  • Longest prefix match. A /24 route beats a /16, which beats the default route 0.0.0.0/0.
  • Administrative distance (AD) breaks ties between sources for the same prefix. Lower is more trusted: connected 0, static 1, RIP 120.
  • Metric breaks ties inside one protocol. RIP's metric is hop count.

If no route matches and there is no default route, the packet is dropped.

Static routing

You type each route by hand. Static routes use no bandwidth or CPU, are predictable, and are easy to secure, but they do not adapt when a link fails and become hard to maintain as the network grows.

  • Next-hop route: ip route 192.168.3.0 255.255.255.0 10.1.1.2
  • Exit-interface route: ip route 192.168.3.0 255.255.255.0 s0/0/0 (common on point-to-point serial links)
  • Default route: ip route 0.0.0.0 0.0.0.0 10.2.2.1, ideal for a stub router with one way out
  • Floating static: add an AD at the end (for example 130) so it only takes over if the dynamic route disappears

Every router in the path needs a route both ways. Forgetting the return route is the most common static routing mistake.

RIPv2
  • Distance-vector protocol; the metric is hop count, max 15 (16 means unreachable).
  • Sends full updates every 30 seconds to multicast 224.0.0.9.
  • Classless: carries the subnet mask, so it supports VLSM. RIPv1 does not.
  • The network command takes a classful network and turns on RIP for every interface inside it. It also advertises those interfaces' subnets.
  • no auto-summary stops RIP from summarizing subnets at classful boundaries.
  • passive-interface stops updates out an interface (such as a LAN with no routers) while still advertising that network.
  • Split horizon prevents a router from advertising a route back out the interface it learned it on.
  • AD is 120, so a static route to the same network always wins.
Reading the routing table

Example line: R 192.168.3.0/24 [120/2] via 10.1.1.2, 00:00:14, Serial0/0/0

  • R is the source code (C connected, L local, S static, S* static default, R RIP).
  • [120/2] is [administrative distance / metric].
  • via 10.1.1.2 is the next-hop router.
  • 00:00:14 is how long since the last RIP update.
  • Serial0/0/0 is the exit interface.
Verify and troubleshoot

Work from the bottom up:

  • show ip interface brief: are the interfaces up/up with the right IPs?
  • show ip route: is the destination network in the table, from the source you expect?
  • ping: can you reach it? Dots mean timeouts; U means a router reported it had no route.
  • traceroute: where does the path stop?
  • show ip protocols: RIP version, networks, passive interfaces, and neighbors.
  • show running-config: what did you actually type?
