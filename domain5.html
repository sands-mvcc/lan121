5.1 Network Troubleshooting Methodology

Master the systematic 7-step approach to network problem solving.

The CompTIA Troubleshooting Methodology

Identify the Problem

  • Gather information - Collect symptoms and error messages
  • Question users - What were they trying to do? When did it start?
  • Identify symptoms - Document all observed issues
  • Determine if anything has changed - Recent updates, configurations
  • Duplicate the problem - Reproduce to understand scope
  • Approach multiple problems individually - One at a time

Establish a Theory of Probable Cause

  • Question the obvious - Check simple things first
  • Consider multiple approaches:
    • Top-to-bottom OSI model (Application → Physical)
    • Bottom-to-top OSI model (Physical → Application)
    • Divide and conquer (Start at middle layers)

Test the Theory

  • If confirmed: Determine next steps to resolve
  • If not confirmed: Reestablish new theory or escalate

Establish a Plan of Action

Create a resolution plan and identify potential effects of the solution

Implement the Solution

Execute the plan or escalate if beyond your authority/expertise

Verify Full System Functionality

Test the fix thoroughly and implement preventive measures if applicable

Document Everything

Record findings, actions taken, outcomes, and lessons learned

🎯 Exam Focus

Memorize the 7 steps in order. Exam questions often present scenarios asking which step comes next or what should be done at each stage.

5.2 Cable Connectivity Issues

Troubleshoot physical layer problems using appropriate tools and techniques.

Cable Specifications and Limitations

Key Specifications

  • Throughput - Data capacity (bps)
  • Speed - Signal propagation rate
  • Distance - Maximum cable length before signal degradation

Cable Considerations

Shielded vs. Unshielded

  • Shielded (STP) - Better EMI protection, more expensive
  • Unshielded (UTP) - Standard Ethernet, cost-effective

Plenum vs. Riser-Rated

  • Plenum-rated - Fire-resistant, for air handling spaces
  • Riser-rated - For vertical runs between floors

Cable Applications

Rollover/Console Cable

Used for direct serial connection to network devices for configuration

Crossover Cable

Connects similar devices (switch-to-switch, PC-to-PC)

Power over Ethernet (PoE)

Delivers both data and power over ethernet cables

Common Cable Issues

📉 Attenuation

Signal weakening over distance. Solution: Use repeaters or shorter cables.

📻 Interference

EMI/RFI disruption. Solution: Use shielded cables or change routing.

📊 dB Loss

Signal power reduction. Measure with optical power meter.

🔌 Incorrect Pinout

Wrong wire arrangement. Test with cable tester or wire map.

❌ Bad Ports

Failed network interfaces. Check LED indicators.

⚡ Open/Short

Broken or touching wires. Identify with multimeter.

Cable Testing Tools

🔧 Cable Crimper

Attaches connectors to cable ends

👊 Punchdown Tool

Terminates wires in patch panels and jacks

🎵 Tone Generator

Traces cables through walls and conduits

🔄 Loopback Adapter

Tests port functionality by creating loop

📡 OTDR

Optical Time-Domain Reflectometer for fiber testing

⚡ Multimeter

Measures electrical properties (voltage, resistance)

🎯 Exam Tip

Know which tool to use for each type of problem. OTDR is for fiber optics, tone generator for cable tracing, multimeter for electrical testing.

5.3 Network Software Tools and Commands

Master command-line utilities and software-based network troubleshooting tools.

Software Tools

📶 WiFi Analyzer

Scans and analyzes wireless networks and signal strength

📦 Protocol Analyzer/Packet Capture

Captures and examines network traffic (Wireshark)

⚡ Bandwidth Speed Tester

Measures network throughput and performance

🔍 Port Scanner

Identifies open ports on network devices

📊 iperf

Network performance measurement tool

🌊 NetFlow Analyzers

Analyzes network traffic patterns and usage

Essential Command Line Tools

ping

ping 8.8.8.8
ping -t google.com (Windows continuous)
ping -c 4 google.com (Linux 4 packets)

Tests connectivity and measures round-trip time

ipconfig/ifconfig/ip

ipconfig /all (Windows)
ifconfig (Linux/macOS)
ip addr show (Modern Linux)

Displays network interface configuration

nslookup/dig

nslookup google.com
dig google.com
dig @8.8.8.8 google.com MX

DNS lookup and troubleshooting

traceroute/tracert

tracert google.com (Windows)
traceroute google.com (Linux/macOS)

Shows network path and identifies routing issues

arp

arp -a
arp -d * (flush table)

Displays and manages ARP table

netstat

netstat -an
netstat -r (routing table)
netstat -s (statistics)

Shows network connections and statistics

nmap

nmap 192.168.1.1
nmap -sn 192.168.1.0/24

Network discovery and port scanning

Network Platform Commands

Common Switch/Router Commands

show interface
show config
show route

Essential commands for Cisco and similar network devices

🎯 Command Memorization

Know the syntax differences between Windows and Linux commands. Practice common switches and parameters for each command.

5.4 Wireless Connectivity Issues

Diagnose and resolve wireless network problems and RF-related issues.

Wireless Specifications and Limitations

Key Metrics

  • Throughput - Actual data transfer rate
  • Speed - Maximum theoretical rate
  • Distance - Coverage area and range
  • RSSI - Received Signal Strength Indication
  • EIRP - Effective Isotropic Radiated Power

Wireless Considerations

Antenna Placement

  • Central location for optimal coverage
  • Avoid interference sources
  • Consider obstacles and building materials
  • Height matters - higher is often better

Antenna Types

  • Omnidirectional - 360° coverage pattern
  • Directional - Focused beam for long distances

Polarization

  • Vertical - Standard for most applications
  • Horizontal - Used in specific scenarios
  • Must match between transmitter and receiver

Channel Utilization

Monitor and optimize channel usage to avoid congestion

AP Association Time

Time required for devices to connect to access points

Site Survey

Comprehensive analysis of RF environment and coverage

Common Wireless Issues

📡 Interference

Channel Overlap - Use non-overlapping channels (1, 6, 11 for 2.4GHz)

📉 Signal Loss

Antenna Cable Attenuation - Check cable connections and quality

📶 RF Attenuation

Physical Obstacles - Walls, metal objects blocking signal

🔐 Authentication Issues

Wrong SSID/Passphrase - Verify network name and password

🔒 Encryption Mismatch

Protocol Incompatibility - WPA/WPA2/WPA3 compatibility

📍 Coverage Issues

Insufficient Coverage - Dead zones or weak signal areas

Advanced Wireless Problems

Captive Portal Issues

  • Browser redirection problems
  • Authentication timeouts
  • HTTPS interference with portal

Client Disassociation Issues

  • Power management settings
  • Roaming problems between APs
  • Driver compatibility issues

🎯 Wireless Troubleshooting Strategy

Start with physical layer (signal strength, interference) then move to logical issues (authentication, encryption). Use WiFi analyzers to visualize the RF environment.

5.5 General Networking Issues

Identify and resolve common network problems across all layers.

Network Analysis Considerations

Essential Review Areas

  • Device Configuration Review - Check settings and parameters
  • Routing Tables - Verify correct paths to destinations
  • Interface Status - Check link state and statistics
  • VLAN Assignment - Ensure correct VLAN membership
  • Network Performance Baselines - Compare current vs. normal performance

Layer 2 Issues

Collisions

Occur in half-duplex environments. Solution: Use full-duplex or switches instead of hubs.

Broadcast Storm

Excessive broadcast traffic flooding network. Check for switching loops and STP configuration.

Duplicate MAC Address

Same MAC on multiple devices. Causes intermittent connectivity issues.

Switching Loops

Redundant paths without STP. Enable Spanning Tree Protocol.

Multicast Flooding

Switch treating multicast as broadcast. Configure IGMP snooping.

Incorrect VLAN

Device in wrong VLAN. Check port VLAN assignment and trunking.

Layer 3 Issues

Duplicate IP Address

Two devices with same IP. Use DHCP reservations or better IP management.

IP Setting Issues

  • Incorrect Gateway - Wrong default gateway prevents internet access
  • Incorrect Subnet Mask - Affects local network communication
  • Incorrect IP Address - Wrong network or host portion
  • Incorrect DNS - Name resolution failures

Asymmetrical Routing

Traffic takes different paths in each direction. Can cause firewall issues.

Routing Loops

Circular routing paths. Check routing protocol configuration and metrics.

Missing Route

No path to destination network. Add static route or fix routing protocol.

DHCP Issues

🔄 Rogue DHCP Server

Unauthorized DHCP server causing conflicts. Use DHCP snooping to prevent.

📊 DHCP Scope Exhaustion

No available IP addresses in pool. Expand scope or reduce lease time.

Infrastructure Issues

Low Optical Link Budget

Insufficient light power in fiber connections. Check connectors and cable quality.

Hardware Failure

Failed network components. Check LED indicators and replace faulty hardware.

Certificate Issues

Expired or invalid certificates causing HTTPS/VPN problems.

Firewall Settings

  • Host-based - Local firewall blocking traffic
  • Network-based - Network firewall rules
  • Blocked Services/Ports - Specific applications blocked

DNS Issues

  • DNS server unavailable
  • Incorrect DNS configuration
  • DNS cache poisoning

NTP Issues

  • Time synchronization problems
  • Authentication failures due to time drift
  • Incorrect time zone settings

Modern Network Challenges

BYOD Challenges

  • Device compatibility issues
  • Security policy enforcement
  • Network access control

Licensed Feature Issues

  • Expired software licenses
  • Feature limitations in trial versions
  • Capacity restrictions

Network Performance Issues

  • Bandwidth saturation
  • Latency problems
  • Jitter affecting VoIP/video

🎯 Troubleshooting Approach

Use the OSI model to systematically isolate issues. Start with physical connectivity, then work up through the layers. Document symptoms before making changes.
