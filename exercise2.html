7
Application Layer
User Interface & Network Services
Data Unit: Data/Messages

🎯 Purpose

  • Provides network services directly to end-users
  • Interfaces between user applications and network
  • Handles user authentication and authorization
  • Manages resource availability and communication

📦 Data Units

  • Data (raw application data)
  • Messages (formatted application data)
  • Application Protocol Data Units (APDUs)
  • User-generated content and requests

🔌 Protocols

  • HTTP/HTTPS (Web browsing)
  • SMTP, POP3, IMAP (Email)
  • FTP/SFTP (File transfer)
  • DNS (Domain name resolution)
  • DHCP (IP address assignment)
  • SNMP (Network management)

💻 Technologies

  • Web browsers (Chrome, Firefox, Safari)
  • Email clients (Outlook, Thunderbird)
  • File transfer applications
  • Network management software
  • APIs and web services

🔧 Devices

  • Application servers
  • Web servers
  • Email servers
  • Proxy servers
  • Application firewalls
  • Load balancers (application level)
6
Presentation Layer
Data Translation & Encryption
Data Unit: Data (Encrypted/Compressed)

🎯 Purpose

  • Translates data between application and network formats
  • Handles data encryption and decryption
  • Manages data compression and decompression
  • Ensures data format compatibility

📦 Data Units

  • Encrypted data
  • Compressed data
  • Formatted data (ASCII, UNICODE)
  • Encoded multimedia content

🔌 Protocols

  • SSL/TLS (Secure communication)
  • ASCII (Text encoding)
  • UNICODE (Character encoding)
  • JPEG, GIF, PNG (Image formats)
  • MPEG (Video compression)
  • ZIP, GZIP (Data compression)

💻 Technologies

  • Encryption algorithms (AES, RSA)
  • Compression algorithms
  • Character encoding systems
  • Data format converters
  • Multimedia codecs

🔧 Devices

  • Encryption/Decryption appliances
  • SSL accelerators
  • Compression engines
  • Format translation gateways
  • Multimedia processing servers
5
Session Layer
Connection Management & Control
Data Unit: Data/Sessions

🎯 Purpose

  • Establishes, manages, and terminates sessions
  • Controls dialogue between applications
  • Provides synchronization and checkpointing
  • Manages full-duplex or half-duplex communication

📦 Data Units

  • Session data
  • Synchronization points
  • Session control information
  • Dialogue tokens

🔌 Protocols

  • NetBIOS (Network Basic Input/Output System)
  • PPTP (Point-to-Point Tunneling Protocol)
  • RPC (Remote Procedure Call)
  • SQL sessions
  • SMB (Server Message Block)
  • NFS (Network File System)

💻 Technologies

  • Session management APIs
  • Authentication systems
  • Connection pooling
  • Session clustering
  • State management systems

🔧 Devices

  • Session border controllers
  • Authentication servers
  • Session management appliances
  • VPN concentrators
  • Terminal servers
4
Transport Layer
End-to-End Data Delivery
Data Unit: Segments (TCP) / Datagrams (UDP)

🎯 Purpose

  • Provides end-to-end data delivery
  • Ensures reliable data transmission
  • Manages flow control and error correction
  • Handles data segmentation and reassembly

📦 Data Units

  • Segments (TCP - reliable)
  • Datagrams (UDP - unreliable)
  • Port numbers for addressing
  • Sequence and acknowledgment numbers

🔌 Protocols

  • TCP (Transmission Control Protocol)
  • UDP (User Datagram Protocol)
  • SCTP (Stream Control Transmission Protocol)
  • SPX (Sequenced Packet Exchange)

💻 Technologies

  • Connection-oriented communication
  • Connectionless communication
  • Flow control mechanisms
  • Error detection and correction
  • Congestion control algorithms

🔧 Devices

  • Layer 4 firewalls
  • Layer 4 load balancers
  • Gateways (transport level)
  • WAN optimizers
  • Transport layer security appliances
3
Network Layer
Routing & Logical Addressing
Data Unit: Packets

🎯 Purpose

  • Routes data between different networks
  • Provides logical addressing (IP addresses)
  • Determines best path for data transmission
  • Handles packet forwarding and fragmentation

📦 Data Units

  • Packets (IP packets)
  • IP addresses (source and destination)
  • Routing information
  • Fragmented packet pieces

🔌 Protocols

  • IP (Internet Protocol v4/v6)
  • ICMP (Internet Control Message Protocol)
  • OSPF (Open Shortest Path First)
  • BGP (Border Gateway Protocol)
  • RIP (Routing Information Protocol)
  • EIGRP (Enhanced Interior Gateway Routing Protocol)

💻 Technologies

  • Routing algorithms
  • Subnetting and VLSM
  • Network Address Translation (NAT)
  • Quality of Service (QoS)
  • MPLS (Multiprotocol Label Switching)

🔧 Devices

  • Routers
  • Layer 3 switches
  • Network firewalls
  • VPN gateways
  • MPLS devices
2
Data Link Layer
Frame Delivery & Error Detection
Data Unit: Frames

🎯 Purpose

  • Provides node-to-node data delivery
  • Handles error detection and correction
  • Manages access to the physical medium
  • Controls flow between adjacent nodes

📦 Data Units

  • Frames (with headers and trailers)
  • MAC addresses (hardware addresses)
  • Error detection codes
  • Flow control information

🔌 Protocols

  • Ethernet (IEEE 802.3)
  • Wi-Fi (IEEE 802.11)
  • PPP (Point-to-Point Protocol)
  • HDLC (High-Level Data Link Control)
  • Frame Relay
  • ATM (Asynchronous Transfer Mode)

💻 Technologies

  • CSMA/CD (Collision Detection)
  • CSMA/CA (Collision Avoidance)
  • Spanning Tree Protocol (STP)
  • VLANs (Virtual LANs)
  • Link aggregation

🔧 Devices

  • Switches (Layer 2)
  • Bridges
  • Network Interface Cards (NICs)
  • Wireless Access Points
  • Smart hubs
1
Physical Layer
Raw Bit Transmission
Data Unit: Bits (1s and 0s)

🎯 Purpose

  • Transmits raw bits over physical medium
  • Defines electrical and mechanical specifications
  • Manages signal timing and synchronization
  • Converts digital data to physical signals

📦 Data Units

  • Bits (binary 1s and 0s)
  • Electrical signals
  • Light pulses (fiber optic)
  • Radio waves (wireless)

🔌 Protocols

  • Ethernet Physical (10BASE-T, 100BASE-TX, 1000BASE-T)
  • RS-232 (Serial communication)
  • USB (Universal Serial Bus)
  • Fiber optic standards
  • Wireless physical standards
  • Coaxial cable standards

💻 Technologies

  • Copper cable transmission
  • Fiber optic transmission
  • Wireless radio transmission
  • Signal modulation techniques
  • Clock synchronization

🔧 Devices

  • Hubs (basic repeaters)
  • Repeaters
  • Cables (UTP, STP, fiber optic)
  • Network Interface Cards (NICs)
  • Modems
  • Transceivers
