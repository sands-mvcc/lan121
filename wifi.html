Security Settings

Configure authentication and encryption protocols to protect your network from unauthorized access.

WPA3 provides the strongest security. Use mixed mode only if you have older devices that don't support WPA3.
Security Note: Never use WEP or Open authentication as they provide no real security protection.
AES is the modern standard and provides strong encryption.
