Channel Planning and Site Survey

2.4 GHz Channel Selection

In the 2.4 GHz band, only channels 1, 6, and 11 are non-overlapping in North America. Proper channel planning prevents interference between adjacent access points.

Site Survey Best Practices:

  • RF Analysis: Measure existing wireless signals and interference sources
  • Coverage Planning: Determine optimal access point placement for coverage and capacity
  • Channel Assignment: Plan non-overlapping channels to minimize interference
  • Power Management: Set appropriate transmit power levels to reduce co-channel interference
  • Antenna Selection: Choose omnidirectional or directional antennas based on coverage requirements
  • Security Zones: Plan guest networks and employee network separation

Network Hubs

Understanding legacy physical layer devices and their limitations

Purpose and Characteristics

Hubs are simple devices that operate at the physical layer of the OSI model. They regenerate and repeat electrical signals to all connected ports, creating a single collision domain for all connected devices.

OSI Layer
Layer 1 (Physical)
Collision Domains
Single for all ports
Broadcast Domains
Single broadcast domain
Duplex Mode
Half-duplex only
Intelligence Level
No MAC learning
Security
Low - all traffic visible

Hub Types and Variations

Hub Type Signal Processing Features Use Cases
Passive Hub No signal amplification Simple connectivity Basic networks (obsolete)
Active Hub Signal amplification Extended range Longer cable runs
Intelligent Hub Signal processing + management SNMP, stacking, basic VLANs Managed environments

Why Hubs Are Obsolete

Performance Impact

In a hub-based network with 10 devices, all devices share the total bandwidth. If the hub operates at 10 Mbps, each device effectively gets only 1 Mbps of available bandwidth during heavy usage.

  • Collision Domain Issues: All ports share the same collision domain, leading to increased collisions as network usage grows
  • Security Vulnerabilities: All traffic is visible to all connected devices, making packet sniffing trivial
  • Half-Duplex Operation: Devices cannot send and receive simultaneously
  • No Intelligence: Cannot learn MAC addresses or make forwarding decisions
  • Bandwidth Sharing: Total bandwidth is shared among all connected devices

Advanced Switch Features

  • Spanning Tree Protocol (STP): Prevents loops in redundant switch topologies
  • Port Security: Limits and controls MAC addresses allowed on each port
  • Link Aggregation: Combines multiple physical links into a single logical link
  • Power over Ethernet (PoE): Delivers power to connected devices through Ethernet cables
  • Quality of Service (QoS): Prioritizes traffic based on application requirements
  • Storm Control: Limits broadcast, multicast, and unicast traffic rates

Router Configuration Example

Basic router configuration for connecting multiple networks:

! Enter configuration mode Router> enable Router# configure terminal ! Set hostname and security Router(config)# hostname Gateway-Router Gateway-Router(config)# enable secret R0ut3rS3cr3t ! Configure WAN interface Gateway-Router(config)# interface gigabitethernet 0/0 Gateway-Router(config-if)# description "WAN Connection to ISP" Gateway-Router(config-if)# ip address dhcp Gateway-Router(config-if)# no shutdown Gateway-Router(config-if)# exit ! Configure LAN interface Gateway-Router(config)# interface gigabitethernet 0/1 Gateway-Router(config-if)# description "LAN Connection" Gateway-Router(config-if)# ip address 192.168.1.1 255.255.255.0 Gateway-Router(config-if)# no shutdown Gateway-Router(config-if)# exit ! Configure default route Gateway-Router(config)# ip route 0.0.0.0 0.0.0.0 gigabitethernet 0/0 ! Enable NAT for internet access Gateway-Router(config)# access-list 1 permit 192.168.1.0 0.0.0.255 Gateway-Router(config)# ip nat inside source list 1 interface gigabitethernet 0/0 overload ! Apply NAT to interfaces Gateway-Router(config)# interface gigabitethernet 0/1 Gateway-Router(config-if)# ip nat inside Gateway-Router(config-if)# exit Gateway-Router(config)# interface gigabitethernet 0/0 Gateway-Router(config-if)# ip nat outside Gateway-Router(config-if)# exit

Router Security Features

Access Control Lists (ACLs)

Routers can implement packet filtering using ACLs to allow or deny traffic based on various criteria including source/destination IP addresses, ports, and protocols.

  • Standard ACLs: Filter based on source IP addresses only
  • Extended ACLs: Filter based on source/destination IPs, ports, and protocols
  • Ingress/Egress Filtering: Apply ACLs to incoming or outgoing traffic
  • Firewall Features: Stateful packet inspection and zone-based firewalls
  • VPN Support: Site-to-site and remote access VPN capabilities

VLAN Security Considerations

VLAN Hopping Attack Prevention

Mismatched native VLANs can create security vulnerabilities. Always ensure consistent native VLAN configuration across trunk links and consider disabling unused VLANs.

  • Native VLAN Security: Change from default VLAN 1 to unused VLAN
  • Trunk Security: Explicitly define allowed VLANs on trunk ports
  • Access Port Security: Enable port security to prevent MAC flooding
  • VLAN Pruning: Remove unnecessary VLANs from trunk links
  • Private VLANs: Use for additional isolation within VLANs
