1.1 The OSI Model

Understanding the seven layers of network communication

Open Systems Interconnection Model

The OSI model is a conceptual framework that standardizes the functions of a telecommunication or computing system into seven abstraction layers. Each layer has a specific role in transmitting data across a network.

7

Application Layer

Provides network services to applications - HTTP, FTP, SMTP, DNS

Protocols: HTTP, FTP, SMTP, DNS
Function: Interface with applications and users
Examples: Web browsers, email clients, file transfer
6

Presentation Layer

Handles data formatting, encryption, and decryption - SSL/TLS, ASCII, MP3, PDF

Functions: Data compression, data encryption (SSL/TLS)
Encoding/Decoding: ASCII, MP3, PDF
Purpose: Ensures data is in a format applications can understand
5

Session Layer

Manages connections between applications - NetBIOS, SIP

Functions: Authentication, authorization, session management
Protocols: NetBIOS, Session Initiation Protocol (SIP)
Purpose: Establishes, maintains, and terminates sessions
4

Transport Layer

Provides reliable data delivery - TCP, UDP

Protocols: Transmission Control Protocol (TCP), User Datagram Protocol (UDP)
Functions: Flow control, congestion control, segmentation
Purpose: Reliable or unreliable delivery between applications
3

Network Layer

Handles routing between networks - IP, ICMP

Protocols: Internet Protocol (IP), Internet Control Message Protocol (ICMP)
Addressing: IP Addresses
Devices: Routers
Purpose: Routing data packets between different networks
2

Data Link Layer

Error-free transmission between nodes - Ethernet, PPP

Sublayers: MAC (Media Access Control), LLC (Logical Link Control)
Protocols: Ethernet, Point-to-Point Protocol (PPP)
Devices: Network Interface Cards (NICs), switches
Purpose: Error detection and correction
1

Physical Layer

Physical connection and hardware - Cables, wireless, voltages

Cabling: Ethernet cables (Cat5e, Cat6), fiber optic cables
Wireless: Bluetooth, WiFi, 5G
Topologies: Bus, star, ring, mesh
Purpose: Physical transmission of raw bits

1.2 Networking Appliances, Applications, and Functions

Essential network devices and their functions

Networking Appliances

🔀 Router

Forwards data packets between different networks using routing tables to determine the best path.

🔌 Switch

Forwards data frames within a LAN using MAC addresses to reach correct destinations.

🛡️ Firewall

Network security system that monitors and controls traffic based on security rules.

🔍 IDS/IPS

Systems that monitor network traffic for malicious activity. IDS detects, IPS prevents.

⚖️ Load Balancer

Distributes network traffic across multiple servers to prevent overload.

🔄 Proxy

Intermediary server providing security, caching, and content filtering.

💾 NAS

Network-Attached Storage provides file-level data access to network clients.

🏗️ SAN

Storage Area Network provides high-speed block-level access to storage devices.

📡 Wireless AP

Allows wireless devices to connect to a wired network.

🎛️ Wireless Controller

Manages and configures multiple wireless access points.

Key Functions

🔐 Virtual Private Network (VPN)

Creates a secure connection over a public network, allowing users to access resources as if they were on a private network.

🚦 Quality of Service (QoS)

A set of techniques to manage network resources and prioritize traffic based on its importance.

⏰ Time to Live (TTL)

A mechanism that limits the lifespan of data packets to prevent them from circulating indefinitely.

1.3 Cloud Concepts and Connectivity Options

Modern cloud computing concepts and deployment models

Cloud Service Models

☁️ SaaS

Software as a Service
Software licensed on subscription, accessed online

🛠️ PaaS

Platform as a Service
Platform for app development, running, and management

🖥️ IaaS

Infrastructure as a Service
Access to computing resources over the internet

Deployment Models

🌐 Public Cloud

Cloud resources owned and operated by third-party providers, available to the general public. Offers scalability and cost-effectiveness but may raise security concerns.

🏢 Private Cloud

Cloud resources used exclusively by a single organization. Provides enhanced security and control but can be more expensive.

🔀 Hybrid Cloud

Combination of public and private cloud resources. Balances cost and security by combining public and private resources.

Cloud Networking Concepts

  • 🌐 Virtual Private Cloud (VPC): Logically isolated section of public cloud for launching resources
  • 🛡️ Network Security Groups: Virtual firewalls controlling VM traffic
  • 📋 Network Security Lists: Similar to security groups but operate at subnet level
  • 🚪 Internet Gateway: Enables VPC communication with the internet
  • 🔄 NAT Gateway: Allows private subnet instances to connect outbound
