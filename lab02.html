DHCP Hands-on Exercise

LAN121 Network Essentials, Moraine Valley Community College

In this exercise you will set up DHCP for a small network. The workstation and the DHCP server are on different networks, so the router has to pass DHCP messages between them. Complete the three configuration tasks, then test that the workstation receives an address.
