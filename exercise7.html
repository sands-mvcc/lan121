Network Security Assessment Tasks

Complete these five tasks to demonstrate your understanding of Network+ Domain 4.0 concepts applied to FreshFlow Systems.

Task 1: Network Security Concepts Analysis

Apply CompTIA Network+ Domain 4.1 concepts to FreshFlow Systems

Scenario:

Dr. Nia Clarke has asked you to prepare a security briefing for the executive team. You need to analyze FreshFlow's current security posture using the CIA triad and identify logical vs. physical security considerations.

Your Tasks:

  1. Evaluate how FreshFlow's assets relate to Confidentiality, Integrity, and Availability requirements
  2. Identify the distinction between logical and physical security controls needed
  3. Recommend authentication methods suitable for different user groups (executives, operators, contractors)
  4. Assess the need for network segmentation across the three facilities
Task 2: Threat Assessment & Attack Analysis

Apply CompTIA Network+ Domain 4.2 concepts to identify potential attacks

Scenario:

FreshFlow has experienced unusual network activity. The packaging facility's PLCs have been responding slowly, and there are reports of unauthorized devices on the network. You must investigate potential attack vectors.

Your Tasks:

  1. Analyze potential DoS/DDoS attack scenarios against OT systems
  2. Investigate possible VLAN hopping attacks between IT and OT networks
  3. Assess risks from rogue DHCP servers and evil twin access points
  4. Evaluate social engineering vulnerabilities across all three facilities
Task 3: Security Controls Implementation

Apply CompTIA Network+ Domain 4.3 concepts for defense strategies

Scenario:

Following the security assessment, you need to design and implement network security features and defense techniques appropriate for FreshFlow's mixed IT/OT environment.

Your Tasks:

  1. Design network access control (NAC) policies for different asset types
  2. Configure device hardening procedures for PLCs, HMIs, and IT systems
  3. Implement appropriate security zones (trusted vs. untrusted) and screened subnets
  4. Design ACLs and content filtering rules for the industrial network
Task 4: Compliance & Risk Management

Integrate regulatory requirements with network security

Scenario:

Rachel Li needs help ensuring FreshFlow meets food safety regulations, PCI DSS requirements for payment processing, and industrial security standards while maintaining operational efficiency.

Your Tasks:

  1. Map PCI DSS requirements to network security controls
  2. Identify food safety data protection requirements
  3. Implement audit logging and monitoring for regulatory compliance
  4. Design incident response procedures for security events affecting production
Task 5: Comprehensive Security Architecture

Design end-to-end security architecture for future growth

Scenario:

With 125% annual growth, FreshFlow needs a scalable security architecture that can support expansion while maintaining security standards. Design a comprehensive security framework for the next 3 years.

Your Tasks:

  1. Design zero-trust architecture principles for FreshFlow's expanding network
  2. Plan security automation and orchestration for growing infrastructure
  3. Create a phased implementation roadmap with priority controls
  4. Develop security metrics and KPIs for ongoing assessment
