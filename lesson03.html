Network Implementation I — Switching, Wireless & Physical Installations

Domain 1 taught you how networks are designed on paper. Domain 2 is where you build them. This lesson covers the physical and data link layer technologies a technician touches every day: Layer 2 switching with VLANs, SVIs, and 802.1Q trunks; interface configuration including speed, duplex, link aggregation, MTU, and jumbo frames; Spanning Tree Protocol and the loops it prevents; wireless networking from 802.11 standards and frequency bands to band steering, BSSIDs, mesh, access point architectures, captive portals, and antennas; and the physical installation itself — racks, PDUs, UPSs, environmental controls, and patch and fiber distribution panels.

🎯

Key Terms & Concepts

🧱VLANTAP TO FLIP
Virtual LAN — a logical broadcast domain created on a switch. Hosts in different VLANs cannot talk without a router or Layer 3 switch, even on the same hardware.
🔀SVITAP TO FLIP
Switch Virtual Interface — a virtual Layer 3 interface assigned to a VLAN (e.g., interface vlan 10). Gives the VLAN an IP address and enables inter-VLAN routing on a Layer 3 switch.
🏷️802.1QTAP TO FLIP
The IEEE trunking standard. Inserts a 4-byte tag into the Ethernet frame carrying a 12-bit VLAN ID (1–4094) so one link can carry many VLANs.
🪪Native VLANTAP TO FLIP
The one VLAN that crosses an 802.1Q trunk untagged (default VLAN 1). Must match on both ends of the trunk — mismatches leak traffic between VLANs.
🔗LACPTAP TO FLIP
Link Aggregation Control Protocol (802.3ad/802.1AX) — bundles multiple physical links into one logical link for more bandwidth and redundancy.
📏MTUTAP TO FLIP
Maximum Transmission Unit — the largest payload a frame can carry. Standard Ethernet MTU is 1500 bytes. Mismatched MTUs cause fragmentation or silent drops.
🐘Jumbo FramesTAP TO FLIP
Ethernet frames with an MTU larger than 1500 bytes — commonly 9000. Reduce per-frame overhead on storage and backup networks, but every device in the path must support them.
🌉STPTAP TO FLIP
Spanning Tree Protocol (802.1D) — blocks redundant Layer 2 paths to prevent switching loops and broadcast storms, then unblocks them if the active path fails.
👑Root BridgeTAP TO FLIP
The switch elected as the reference point of the spanning tree — the one with the lowest bridge ID (priority + MAC address). All path decisions are measured from it.
✉️BPDUTAP TO FLIP
Bridge Protocol Data Unit — the message switches exchange to elect the root bridge and calculate the loop-free topology.
🧲Band SteeringTAP TO FLIP
An AP feature that nudges dual-band capable clients off crowded 2.4 GHz and onto the faster, cleaner 5/6 GHz bands.
📶Channel WidthTAP TO FLIP
How much spectrum a Wi-Fi channel occupies — 20, 40, 80, or 160 MHz. Wider = faster, but consumes more spectrum and increases interference risk.
🔖BSSIDTAP TO FLIP
Basic Service Set Identifier — the MAC address of an individual access point radio. One SSID broadcast from three APs = three BSSIDs.
🌐ESSIDTAP TO FLIP
Extended Service Set Identifier — the same SSID shared across multiple APs so clients can roam seamlessly through a building.
🕸️Mesh NetworkTAP TO FLIP
Wireless topology where APs relay traffic to each other over the air — only one node needs a wired uplink. Great where cabling is impractical.
🚧Captive PortalTAP TO FLIP
A web page that intercepts new wireless clients and requires login, payment, or acceptance of terms before granting network access. Standard on guest Wi-Fi.
🔌PDUTAP TO FLIP
Power Distribution Unit — a rack-mounted power strip that distributes power to equipment. Metered and switched PDUs add load monitoring and remote outlet control.
🔋UPSTAP TO FLIP
Uninterruptible Power Supply — battery backup that bridges outages and conditions power. Sized in VA/watts; runtime covers graceful shutdown or generator start.

Lesson Content

By default, every port on a switch belongs to one big broadcast domain — a broadcast from any host reaches every other host. A VLAN (Virtual LAN) carves that switch into multiple logical switches. Ports assigned to VLAN 10 can only talk to other VLAN 10 ports; VLAN 20 is a completely separate broadcast domain, even though both live on the same physical hardware.

VLANs deliver three big wins:

  • Security — Accounting traffic never touches Guest traffic. Crossing VLANs requires a router, where you can apply ACLs and firewall rules.
  • Performance — smaller broadcast domains mean less broadcast noise per host.
  • Flexibility — membership follows configuration, not cabling. Move a user to a new department without re-pulling cable.

Access ports

A port that connects an end device (PC, printer, camera) is an access port — it belongs to exactly one data VLAN, and frames on it are untagged. The host has no idea a VLAN exists:

switchport mode access · switchport access vlan 10

SVIs — giving a VLAN an IP address

VLANs isolate traffic; eventually those networks still need to reach each other. On a Layer 3 switch, you create a Switch Virtual Interface (SVI) — a virtual routed interface for the VLAN. Assign it an IP address, and it becomes the default gateway for every host in that VLAN. The switch then routes between SVIs in hardware — no external router needed.

interface vlan 10 · ip address 192.168.10.1 255.255.255.0

🎓Exam note: Know the vocabulary cold: a VLAN is a broadcast domain, an access port carries one untagged VLAN, and an SVI is the virtual Layer 3 interface that lets a multilayer switch route between VLANs. Lesson 4 adds the alternative: router-on-a-stick with subinterfaces.

Trunk ports and the 802.1Q tag

If VLAN 10 and VLAN 20 both need to travel between two switches, you could burn one cable per VLAN — or use a single trunk port. The IEEE 802.1Q standard inserts a 4-byte tag into each Ethernet frame right after the source MAC address. Inside that tag, a 12-bit VLAN ID (values 1–4094) tells the receiving switch which VLAN the frame belongs to.

  • Native VLAN — the one VLAN a trunk carries untagged (default: VLAN 1). Both ends of the trunk must agree; a native VLAN mismatch silently leaks frames between VLANs. Best practice: move it off VLAN 1 to an unused VLAN.
  • Voice VLAN — a special second VLAN on an access port so an IP phone and the PC plugged into it ride separate VLANs on one cable, letting QoS prioritize voice.

Interface configuration: speed & duplex

Modern interfaces autonegotiate speed (100 Mbps / 1 / 2.5 / 10 Gbps) and duplex. Full duplex sends and receives simultaneously; half duplex takes turns. The classic failure: one side hard-coded to full, the other left on auto — the auto side falls back to half duplex. The link works, but crawls, logging late collisions and CRC errors. Configure both ends identically: both auto, or both hard-coded.

Link aggregation (LACP)

LACP (802.3ad/802.1AX) bundles 2–8 physical links into one logical link — an EtherChannel or port channel. You get combined bandwidth, automatic failover if a member link dies, and STP treats the whole bundle as a single interface (so no blocked ports inside it). All member links must match: same speed, same duplex, same VLAN configuration.

MTU & jumbo frames

The MTU (Maximum Transmission Unit) is the largest payload one frame can carry — 1500 bytes for standard Ethernet. Jumbo frames raise that to roughly 9000 bytes, so one frame does the work of six. Fewer frames means less header overhead and less CPU interrupt load — a real win on storage (iSCSI), backup, and virtualization networks.

⚠️The jumbo frame rule: every device in the path — both NICs and every switch between them — must support the same jumbo MTU. One standard-MTU device in the middle causes fragmentation at best and silently dropped frames at worst. Enable jumbo frames on purpose-built segments, not casually across the whole LAN.
🎓Exam note: Scenario questions love the duplex mismatch ("link is up but throughput is terrible, errors incrementing") and the 802.1Q facts: 4-byte tag, 12-bit VLAN ID, native VLAN untagged.

Redundant links between switches are good design — until you remember that Ethernet frames have no TTL. Connect three switches in a triangle with nothing to stop it, and a single broadcast circulates forever, multiplying each lap: a broadcast storm. MAC address tables flap, CPUs peg at 100%, and the network melts in seconds.

Spanning Tree Protocol (STP, IEEE 802.1D) solves this by logically blocking redundant paths while keeping them on standby. Switches exchange BPDUs (Bridge Protocol Data Units) to build one loop-free tree:

  • 1. Elect the root bridge — the switch with the lowest bridge ID (priority + MAC address) wins. Lower priority wins; on a tie, lowest MAC wins. Set priority deliberately so your core switch is the root — don't let an old closet switch win by accident.
  • 2. Pick port roles — every non-root switch selects one root port (best path toward the root); each segment gets one designated port; everything left over is blocked.
  • 3. Fail over — if the active path dies, a blocked port transitions to forwarding and traffic keeps flowing.

Port states

Classic 802.1D ports walk through Blocking → Listening → Learning → Forwarding (plus Disabled), taking 30–50 seconds to converge. Rapid Spanning Tree (RSTP, 802.1w) collapses the states to Discarding / Learning / Forwarding and converges in seconds — it's the default on modern gear.

💡Field tip: Enable PortFast (edge port) on access ports facing PCs so users don't wait through STP convergence at boot — and pair it with BPDU Guard, which shuts the port down if a switch ever appears where a PC should be.
🎓Exam note: Root bridge = lowest bridge ID (priority first, MAC as tiebreaker). STP's job in one sentence: prevent Layer 2 loops while preserving redundant paths. Symptoms of a loop: broadcast storm, MAC table instability, total slowdown.

Frequency bands — the range vs. speed trade

  • 2.4 GHz — best range and wall penetration, but only 3 non-overlapping channels (1, 6, 11) and it's crowded: microwaves, Bluetooth, baby monitors, and every neighbor's router.
  • 5 GHz — many more non-overlapping channels and higher speeds; shorter range; some channels require DFS (radar avoidance).
  • 6 GHz (Wi-Fi 6E) — a huge swath of clean spectrum, exclusively for modern clients; shortest range of the three.

Channels & channel width

Each band is sliced into channels. In 2.4 GHz, channels are 5 MHz apart but a signal is ~20 MHz wide — so adjacent channels overlap and interfere. That's why proper 2.4 GHz design uses only 1, 6, and 11, tiling them like a honeycomb so neighboring APs never share a channel. Channel width (20/40/80/160 MHz) is the throughput dial: wider channels bond more spectrum for speed, but in 2.4 GHz a 40 MHz channel swallows the whole band. Rule of thumb: 20 MHz in 2.4 GHz, 40–80 MHz in 5 GHz, wider only where spectrum is clean.

Band steering

Many clients stubbornly cling to 2.4 GHz because its signal reads "stronger." Band steering is an AP feature that detects dual-band-capable clients and nudges them onto 5/6 GHz — typically by delaying or ignoring their 2.4 GHz probe requests — reserving 2.4 GHz for legacy and IoT devices that have no choice.

🎓Exam note: Memorize the pairs — 2.4 GHz = range + congestion + channels 1/6/11; 5 GHz = speed + more channels + DFS; 6 GHz = Wi-Fi 6E only. "Which channels should three neighboring APs use in 2.4 GHz?" is a gift question: 1, 6, 11.

SSID, BSSID, ESSID — three IDs, one network

  • SSID — the human-readable network name you tap on ("MVCC-WiFi").
  • BSSID — the MAC address of an individual AP radio. Three APs broadcasting the same SSID = three different BSSIDs. Your laptop associates with a BSSID, not a name.
  • ESSID — the same SSID extended across multiple APs so clients roam between them seamlessly. Enterprise Wi-Fi is one big ESS.

Mesh networks

In a mesh, APs backhaul traffic to each other over the air — only one node needs a wired connection. Perfect for warehouses, outdoor spaces, historic buildings, and homes where pulling cable is impractical. The trade-off: each wireless hop consumes airtime and cuts throughput, so wire what you can.

Captive portals

A captive portal intercepts a newly connected client's first web request and redirects it to a gateway page — accept the terms, enter a voucher, watch an ad, or log in — before granting access. It's the standard front door for guest networks in hotels, airports, coffee shops, and campuses, and it keeps guests segmented (usually on their own VLAN — see Section 1) from internal resources.

Antenna types

  • Omnidirectional — radiates 360° in the horizontal plane (a doughnut shape). The default for ceiling-mounted APs covering open areas.
  • Directional — focuses energy in one direction for greater range/gain: patch/panel antennas mount on a wall and cover a hallway or room; Yagi antennas reach further down a line; parabolic dishes handle long point-to-point building-to-building links.
💡Design tip: Antenna choice is placement, not preference: omni in the middle of the space, directional at the edge pointing in. Never cover a parking lot by cranking power on an indoor omni — you'll create interference and a security footprint outside your walls.

Installation locations & rack layout

Structured cabling terminates in the MDF (Main Distribution Frame — the building's primary equipment room) and IDFs (Intermediate Distribution Frames — closets serving each floor or area, uplinked to the MDF). Inside, equipment mounts in 19-inch racks measured in rack units (1U = 1.75"); a full-height rack is typically 42U.

  • Heavy gear low — UPS and batteries at the bottom for stability.
  • Patch panels adjacent to switches — short, tidy patch cords beat a cable waterfall.
  • Respect airflow — most gear breathes front-to-back; match port-side intake/exhaust to your hot-aisle/cold-aisle layout so one device's exhaust isn't another's intake.
  • Label and lock — label every cable and use lockable racks/doors; physical access is the first security control.

Power: PDU, UPS & load

  • PDU (Power Distribution Unit) — the rack's power strip. Metered PDUs report load; switched PDUs let you power-cycle an outlet remotely at 2 a.m. instead of driving in.
  • UPS (Uninterruptible Power Supply) — battery backup that also conditions power (surges, sags, brownouts). An online/double-conversion UPS powers the load from the battery path continuously — zero transfer time.
  • Power load & voltage — add up equipment draw (watts/VA) and keep the UPS below ~80% of capacity, with runtime for a graceful shutdown or generator start. Verify circuit voltage (120 V vs 208/240 V) and plug types before installation day.

Environmental factors

  • Temperature — keep intake air roughly 64–80 °F (18–27 °C); heat is the number-one hardware killer.
  • Humidity — target ~40–60% RH: too dry invites static discharge, too damp invites condensation and corrosion.
  • Fire suppression — water sprinklers destroy electronics; equipment rooms use clean-agent gas systems (FM-200, Novec 1230, inert gas) that suppress fire without residue.

Patch panels & fiber distribution panels

Horizontal cable runs from wall jacks punch down once into a patch panel; short patch cords then connect panel ports to switch ports. Moves and changes happen at the patch cord — the permanent cabling is never disturbed. Fiber distribution panels do the same job for fiber, protecting splice trays and connectors, managing bend radius, and safely parking unused strands.

🎓Exam note: Know PDU vs UPS (distribution vs backup), why humidity has both a floor (ESD) and a ceiling (condensation), why clean-agent suppression replaces water, and the purpose of patch/fiber panels: a permanent termination point so all changes happen at the patch cord.

Knowledge Check

Q1. Hosts in VLAN 10 cannot communicate with hosts in VLAN 20 on the same Layer 2 switch. Why?
Rationale: VLANs are separate broadcast domains by design. Traffic between them must be routed — by a router or by SVIs on a Layer 3 switch. That isolation is the whole point.
Q2. What does the 802.1Q standard add to an Ethernet frame on a trunk link?
Rationale: 802.1Q inserts a 4-byte tag after the source MAC address; 12 of those bits carry the VLAN ID (1–4094). Ethernet frames never gain a TTL — which is exactly why STP exists.
Q3. A link shows "up/up" but throughput is terrible and the interface counters show late collisions and CRC errors. Most likely cause?
Rationale: The classic duplex mismatch signature: link is up, performance is awful, late collisions and CRC errors increment. Configure both ends to autonegotiate, or hard-code both identically.
Q4. In STP, which switch becomes the root bridge?
Rationale: Lowest bridge ID wins: priority is compared first, and the lowest MAC address breaks ties. Set the core switch's priority low on purpose so an old closet switch never wins by having an ancient (low) MAC.
Q5. Your storage team wants jumbo frames on the iSCSI network. Which condition is required?
Rationale: Jumbo frames only work end-to-end. One device stuck at MTU 1500 in the path causes fragmentation or silent drops. Enable them deliberately on isolated storage/backup segments.
Q6. You're deploying three access points in adjacent classrooms on 2.4 GHz. Which channel plan avoids co-channel interference?
Rationale: In 2.4 GHz, a ~20 MHz signal on channels spaced 5 MHz apart means only 1, 6, and 11 don't overlap. Adjacent-channel overlap (1,2,3) is actually worse than sharing one channel.
Q7. A campus has 200 access points all broadcasting "MVCC-WiFi." What term describes the unique MAC-address identifier of each individual AP radio?
Rationale: The BSSID is the MAC address of a single AP radio. The SSID is the shared name; the ESSID describes that name extended across all 200 APs so clients roam seamlessly.
Q8. Which fire suppression approach is appropriate for a server room, and why?
Rationale: Clean-agent systems (FM-200, Novec 1230, inert gas) extinguish fires without water or residue. A sprinkler discharge often destroys more equipment than the fire it stops.
