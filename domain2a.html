2.1 Routing Technologies

Static vs Dynamic Routing

Static Routing

Definition: Routes manually configured by network administrators that don't change automatically.

Characteristics:

  • Administrative Distance: 1
  • No protocol overhead
  • Predictable routing paths
  • Suitable for small, stable networks
  • Requires manual updates when topology changes

Dynamic Routing

Definition: Routes automatically calculated and updated by routing protocols based on network topology changes.

Types:

  • Distance Vector (RIP, EIGRP)
  • Link State (OSPF, IS-IS)
  • Path Vector (BGP)

Dynamic Routing Protocols

Enhanced Interior Gateway Routing Protocol (EIGRP)

Type: Hybrid/Advanced Distance Vector

Key Features:

  • Administrative Distance: 90
  • Cisco proprietary (now open standard)
  • Uses DUAL algorithm
  • Supports unequal-cost load balancing
  • Fast convergence
  • Metric: Bandwidth, Delay, Load, Reliability, MTU

Open Shortest Path First (OSPF)

Type: Link State

Key Features:

  • Administrative Distance: 110
  • Open standard (RFC 2328)
  • Uses Dijkstra's SPF algorithm
  • Hierarchical design with areas
  • Fast convergence
  • Metric: Cost (based on bandwidth)

Border Gateway Protocol (BGP)

Type: Path Vector (External Gateway Protocol)

Key Features:

  • Administrative Distance: 20 (eBGP), 200 (iBGP)
  • Internet routing protocol
  • Policy-based routing
  • Path attributes for route selection
  • Used between Autonomous Systems

Route Selection

Administrative Distance

Used to rank routes from different routing protocols (lower is better):

  • Connected Interface: 0
  • Static Route: 1
  • EIGRP: 90
  • OSPF: 110
  • RIP: 120

Prefix Length (Longest Match)

Routes with longer subnet masks (more specific) are preferred over less specific routes.

Metric

Used by routing protocols to determine the best path when multiple routes exist to the same destination.

Address Translation

Network Address Translation (NAT)

Translates private IP addresses to public IP addresses for internet connectivity.

Port Address Translation (PAT)

Also known as NAT Overload - maps multiple private addresses to a single public address using different port numbers.

Benefits:

  • Conserves public IP addresses
  • Provides security through address hiding
  • Allows multiple devices to share single public IP

First Hop Redundancy Protocol (FHRP)

Provides gateway redundancy by allowing multiple routers to share a virtual IP address.

Virtual IP (VIP)

A shared IP address used by FHRP that can be moved between routers for redundancy.

Common FHRP Protocols:

  • HSRP (Hot Standby Router Protocol) - Cisco
  • VRRP (Virtual Router Redundancy Protocol) - Standard
  • GLBP (Gateway Load Balancing Protocol) - Cisco

Subinterfaces

Virtual interfaces that allow a single physical interface to be divided into multiple logical interfaces.

Use Cases:

  • VLAN routing (Router-on-a-stick)
  • Multiple IP subnets on one interface
  • Frame Relay subinterfaces
  • Point-to-point connections

2.2 Switching Technologies

Virtual Local Area Networks (VLANs)

Logical grouping of devices on the same broadcast domain, regardless of physical location.

VLAN Database

Stores VLAN configuration information on the switch, including VLAN IDs, names, and port assignments.

Switch Virtual Interface (SVI)

Virtual Layer 3 interface that provides IP connectivity for a VLAN.

SVI Functions:

  • Default gateway for VLAN hosts
  • Inter-VLAN routing
  • Management access to switch
  • Layer 3 services for VLAN

Interface Configuration

Native VLAN

VLAN that carries untagged traffic on a trunk link (default VLAN 1).

Voice VLAN

Separate VLAN for VoIP traffic to ensure quality of service and security separation.

802.1Q Tagging

Standard method for VLAN identification in Ethernet frames.

802.1Q Frame Fields:

  • TPID (Tag Protocol Identifier): 0x8100
  • Priority: 3 bits for QoS
  • CFI (Canonical Format Indicator): 1 bit
  • VLAN ID: 12 bits (4096 possible VLANs)

Link Aggregation

Combining multiple physical links into a single logical link for increased bandwidth and redundancy.

Technologies:

  • LACP (Link Aggregation Control Protocol) - IEEE 802.3ad
  • PAgP (Port Aggregation Protocol) - Cisco proprietary
  • Static aggregation (manual configuration)

Speed and Duplex

Speed: Data transmission rate (10/100/1000 Mbps, 10 Gbps, etc.)

Duplex: Communication direction capability

  • Half Duplex: One direction at a time
  • Full Duplex: Both directions simultaneously
  • Auto-negotiation: Automatic speed/duplex detection

Spanning Tree Protocol (STP)

Prevents Layer 2 loops in switched networks by blocking redundant paths.

STP Variants:

  • STP (802.1D) - Original standard
  • RSTP (802.1w) - Rapid Spanning Tree
  • MSTP (802.1s) - Multiple Spanning Tree
  • PVST+ - Per-VLAN Spanning Tree Plus (Cisco)

Port States:

  • Blocking: Receives BPDUs only
  • Listening: Processes BPDUs
  • Learning: Learns MAC addresses
  • Forwarding: Full operation
  • Disabled: Administratively down

Maximum Transmission Unit (MTU)

Largest size packet/frame that can be transmitted over a network interface.

Standard MTU Sizes:

  • Ethernet: 1500 bytes
  • PPPoE: 1492 bytes
  • Token Ring: 4464 bytes
  • FDDI: 4352 bytes

Jumbo Frames

Ethernet frames larger than the standard 1500-byte MTU, typically up to 9000 bytes.

Benefits:

  • Reduced CPU overhead
  • Improved throughput for large transfers
  • Better efficiency in data centers
  • Reduced frame processing overhead

What is EIGRP?
Enhanced Interior Gateway Routing Protocol - A Cisco hybrid routing protocol that uses DUAL algorithm with AD of 90
What does SVI stand for?
Switch Virtual Interface - A virtual Layer 3 interface that provides IP connectivity for a VLAN
What is the purpose of Spanning Tree Protocol?
STP prevents Layer 2 loops in switched networks by blocking redundant paths and maintaining a loop-free topology
What is PAT?
Port Address Translation (NAT Overload) - Maps multiple private addresses to a single public address using different port numbers
What is 802.1Q?
IEEE standard for VLAN tagging in Ethernet frames, adding a 4-byte tag with VLAN ID information
What is FHRP?
First Hop Redundancy Protocol - Provides gateway redundancy using protocols like HSRP, VRRP, and GLBP with Virtual IP addresses
